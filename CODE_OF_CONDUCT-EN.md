# Community code of conduct

> [简体中文](CODE_OF_CONDUCT.md) | **English**

YAQMC welcomes contributors with different backgrounds, experience, and viewpoints. Discussions should focus on
facts, code, reproduction steps, and verifiable evidence.

Be respectful, criticize technology and behavior rather than people, distinguish fact from inference or preference,
protect account/private/security data, and correct mistakes transparently. Harassment, discrimination, threats,
doxxing, credential disclosure, unpatched exploit publication, subscription/copyright bypass material, spam,
impersonation, and destructive activity are not accepted.

Maintainers may edit or remove violating content, restrict participation, or report serious events to the platform.
Use the private path in [SECURITY.md](SECURITY.md) for security or privacy incidents.
