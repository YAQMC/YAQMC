# Support

> [简体中文](SUPPORT.md) | **English**

Read [README-EN.md](README-EN.md), the [English docs index](docs/README.md), and existing issues first. Use the
Chinese issue forms for bugs, feature requests, or Linux compatibility. Include version, platform, reproduction,
expected/actual behavior, and redacted logs or screenshots. Never upload cookies, OAuth codes, tokens, ekeys,
signed URLs, real profile data, or full response bodies. Report unpatched security issues privately through
[SECURITY.md](SECURITY.md).
