# Support

> [简体中文](SUPPORT.md) | **English**

Read [README-EN.md](README-EN.md), the [English docs index](docs/README.md), and existing issues first. For most
reports, use **Settings → About → Report a problem** inside YAQMC — the app prefills the technical fields, can
generate a redacted diagnostic bundle ZIP, and opens the GitHub Issue form in your default browser so you can
review it before pressing Submit. Full details are in [Issue reporting](docs/issue-reporting.md), with the
matching privacy contract in [Security & privacy](docs/security.md).

If YAQMC cannot start, fall back to the Chinese issue forms (bug / Linux compatibility / feature request). Include
version, platform, reproduction, expected/actual behavior, and redacted logs or screenshots from
`%LOCALAPPDATA%\org.yaqmc.desktop\logs` (Windows) or
`$XDG_DATA_HOME/org.yaqmc.desktop/logs` (Linux). See [data locations](docs/data-locations.md)
for fallbacks. Never upload cookies, OAuth codes, tokens, ekeys, signed URLs, real profile data, or full response
bodies. Report unpatched security issues privately through [SECURITY.md](SECURITY.md).
