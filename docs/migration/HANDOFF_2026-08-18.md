## 2. Architecture / migration state

### 2.1 Current system

YAQMC is a desktop music client. The Electron host is the migration target;
the Tauri host **still exists** for parity and comparison until P13 (which
must not start before the P12 / ACC gate).

```
React/TypeScript renderer  (src/, Vite in unpackaged dev, app:// when packaged)
        │  window.yaqmc (preload contextBridge: invoke / on only)
        ▼
Electron preload           (apps/desktop/preload)
        │  IPC
        ▼
Electron Main = Desktop Host   (apps/desktop/main)
        │  stdio framed protocol (yaqmc-protocol)
        ▼
Rust yaqmc-core            (crates/yaqmc-core)  ← authoritative Core
        │
        ├── PlayerService (authoritative player)
        ├── ACL / method registry (authoritative origin checks)
        ├── storage, plugins, local API, system media, QQ in-tree provider
        └── events: player://snapshot, lyrics://*, host://command, …
```

TypeScript SDK: `@yaqmc/client` (`YaqmcClient`). The renderer talks to Core
through the client + host bridge, not by opening stdio itself.

**Origin model**

- Electron Main assigns the **trusted window origin** (`OriginClass::Main` vs
  lyrics surfaces vs unlock overlays). The renderer **cannot spoof** origin.
- Core ACL remains **authoritative**. Do not “fix” ACL denials by adding
  `host` to methods that are main-renderer continuations.
- Dialog-split methods (`diagnostics_export_bundle_to`,
  `preferences_set_background_from`, `plugin_install_from`) are
  **main-origin** continuations after a **host-owned** picker. See §10.

**Player authority**

`PlayerService` in Core remains the only player state machine. The renderer
interpolates snapshots for UI; it must not become a second source of truth.

### 2.2 Player invariants that must not be weakened

Do not remove or bypass these to “make seek faster” or “make EOS simpler”:

| Invariant | Role |
| --- | --- |
| `session_id` | Identifies the playback session. Stale commands/events from a previous session must not win. |
| `snapshot_revision` | Monotonic snapshot generation. UI/host must not apply an older snapshot over a newer one. |
| `seek_revision` / `last_seek_revision` | Fences stale seek results and stale EOS against a newer seek intent. |
| `source_generation` | Source identity generation. |
| `load_generation` | Load/reload generation (post-EOS reload vs in-place seek). |
| `SeekMailbox` | Coalesces rapid seeks. Mailbox only works if seek RPC **returns**; a 15s blocking `try_seek` prevents coalescing. |
| Stale EOS / result fencing | An EOS or seek-result tagged with an older revision must not clobber a newer session/seek. |

`1d6b535` attempted to restore EOS/repeat, non-blocking seek, and lyric-clock
sampling **without** dropping these fences. Automated tests for that commit
are PASS-AUTO only. HUMAN later contradicted PLAY-01 acceptance — see §5.

## 10. Development / runtime traps already discovered

### 10.1 Stale Core problem

Unpackaged Electron **previously** preferred:

`apps/desktop/resources/core/yaqmc-core.exe`

That binary was **stale**. Symptoms looked like ACL / unknown-method failures
(`not allowed from host`) even after origin-stamping landed.

**Current unpackaged resolution** (see `resolveCoreLaunch` / supervisor):

1. `YAQMC_CORE_BIN` if set
2. Packaged resources when packaged
3. Cargo debug/release (unpackaged) — respects `CARGO_TARGET_DIR` if set
4. Staged `apps/desktop/resources/core/`
5. Cargo fallback

A typical path when `CARGO_TARGET_DIR` is unset:

`D:\YAQMC\.worktrees\electron-migration\target\debug\yaqmc-core.exe`

If this machine uses `CARGO_TARGET_DIR` (example used in prior local builds:
`E:\cargo-target\yaqmc-electron-migration`), **host.log is the authority**.
Do not hard-code an `E:\` path in the repo.

`host.log` records:

`supervisor start binary=...`

**Always check this before debugging protocol mismatches.** Rotating
`host.log` lives in the **Core log directory** (`HOST_LOG_FILE_NAME` in
`apps/desktop/main/host-log.ts`). On Windows that is expected under
`%LOCALAPPDATA%\org.yaqmc.desktop\logs` (see `docs/migration/data-paths.md`).

`npm run dev:desktop` stages a debug Core as part of orchestration; still
confirm the supervisor line.

### 10.2 Fake E2E trap

Playwright previously used `YAQMC_CORE_BIN` / fake paths and could stay
**green** while the real development path was broken.

- `npm run test:e2e` = Chromium fake UI.
- `npm run test:e2e:electron` = Electron specs; several are fake-window /
  geometry / tray **programmatic** coverage.

**Production-chain regressions must exercise the same Main / preload / Core
path as `npm run dev:desktop`.** Do not accept PLAY-01 from fake E2E.

### 10.3 Dialog split (`_to` / `_from`)

Authorized **main renderer** → **host-owned** picker/dialog → Core method
continuation remains **`origin=main`**.

Do **not** add `host` to those ACLs to make them pass. That would be the
wrong fix (already seen as a HUMAN dead-end before `ca40682` / `bf43c53`).

### 10.4 Protocol cap

Preserve:

- **1 MiB** default method cap
- method-specific caps where defined
- **32 MiB** hard cap

The background fix (`c992653`) deliberately **stopped carrying large base64
image data through the Core protocol** instead of increasing caps. Do not
raise caps to move artwork or backgrounds.
