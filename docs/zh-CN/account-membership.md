# QQ 音乐账号会员模型

> **简体中文** | [English](../account-membership.md)

YAQMC 分别建模主会员、会员生命周期和附加权益。主会员只有免费、绿钻、超级会员和未知；豪华、年费、
家庭、体验等标记以弱化的附加权益显示，不能覆盖主会员。

QQ 规范化器把 `identity.vip` 视为绿钻，把顶层 `svip` 结果视为超级会员；`HugeVip` 是豪华绿钻附加权益，
不是超级会员。缺失、畸形或互相矛盾的标记会得到未知。授权过期属于账号状态，不能伪装成免费账号。

界面只接收规范化昵称、白名单头像、掩码身份、主会员、生命周期、到期时间和附加权益。原始响应、Cookie、
UIN 和授权材料不会进入组件属性或“复制诊断信息”。音质选择的独立模型见[播放权益](entitlement.md)。
