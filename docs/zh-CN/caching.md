# 持久化与缓存

> **简体中文** | [English](../caching.md)

`StorageService` 将耐久结构化状态和可丢弃响应文件分开保存。

## SQLite

应用数据目录中的 `library.sqlite3` 使用 `user_version` 迁移、WAL 和外键，保存：

- 有过期时间的目录元数据/歌词 JSON；
- 文件缓存索引与 LRU 时间；
- 设置、最近搜索（最多 100）、播放历史（最多 2,000）；
- 单份队列/播放器快照；
- 以随机会话 scope 隔离的账号页面与完整账号音乐库投影。

公开首页/搜索 TTL 为 15 分钟，专辑/歌单 24 小时，歌词 30 天。账号收藏为 2 分钟，账号歌单、详情
和最近播放为 5 分钟。网络故障可返回明确标记 stale 的一致公开数据；认证过期绝不能使用旧账号数据。
媒体 URL 和秘密不写入 SQLite。

账号缓存键只包含随机 scope 和 outward cursor 哈希，不包含 UIN、提供器原始 cursor 或凭据。重启后
非终止首页会先重新请求再产生新 cursor；完整刷新按 epoch 累积所有页，终页时一次原子替换投影。
注销或换号会删除整个 `qqmusic-account` 缓存类别。

## 文件缓存

| 类型 |  总上限 |                    单文件上限 | 淘汰 |
| ---- | ------: | ----------------------------: | ---- |
| 媒体 | 256 MiB | 128 MiB（加密源可使用总上限） | LRU  |
| 图片 |  64 MiB |                         5 MiB | LRU  |

最多并发四个下载。文件名来自稳定媒体身份的 SHA-256，不来自签名 URL。下载写入随机 `.part`，同时
校验声明大小和实际大小，flush 后原子重命名。SQLite 内的相对路径在读取、淘汰、删除前都会重新校验。
“清除缓存”只删除索引内的可丢弃内容，不删除设置、历史、队列或操作系统安全存储中的秘密。

封面只允许从审核过的 HTTPS 域名下载，原生层缓存字节后以 data URI 返回渲染器。前端用小型 Promise
缓存合并并发请求，并在页面取消后忽略迟到结果。
