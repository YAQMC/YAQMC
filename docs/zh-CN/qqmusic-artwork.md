# QQ 音乐封面分辨率证据

> **简体中文** | [English](../qqmusic-artwork.md)

本文记录集中式 `ArtworkResolver` 使用的可观测行为，不把它描述成永久的 QQ 音乐 API 保证。

## 选择策略

提供器返回一个带有普通来源和实测变体的 `Artwork`。界面按场景选择：播放器/队列使用 150 px，媒体卡片
使用 300 px，专辑和歌单详情使用 500 px，全屏歌词与背景使用 800 px。解析器选择满足目标的最小已知
变体；没有满足项时使用最大实测变体。来源尺寸不可信时保留原 URL，不合成更大地址。

专辑封面优先于榜单横幅或无关 MV 图。QQ 提供器负责 URL 构造，页面组件不能自行拼 CDN 地址。

## 在线只读核验

2026-08-14 使用公开目录和图片响应核验，不携带账号凭据。G.E.M.《新的心跳》的专辑 MID
`003c616O2Zlswm` 在 150/300/500/800 请求中分别解码为对应尺寸，1000 返回 404；周杰伦《七里香》MID
`003DFRzD192KKD` 同样验证到 800。公开“飙升榜”提供 500×500 `headPicUrl`，首曲 “Broken Trust” 的
500/800 专辑图也按请求尺寸解码。这些证据支持当前 800 px 上限。

## 缓存与安全

每个选择后的变体使用自己的 URL 派生缓存键。原生缓存有容量上限并验证图片 MIME；远程封面只接受精确
HTTPS host `y.gtimg.cn` 与 `qpic.y.qq.com`，请求不附带账号凭据。
