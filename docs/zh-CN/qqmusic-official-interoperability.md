Windows 注册了 `.mflac`、`.mgg`、`.mmp4`、`.qmc0/2/3/4/6/8`、`.qmcflac`、`.qsc3`、`.tkm` 文件
关联，打开命令是已签名客户端的 `/play "%1"`。注册的 URL 协议中没有发现由 QQ 音乐拥有的歌曲、专辑、
歌单或歌手 scheme。协议 DLL 内部存在解析器符号，但内部符号不能证明存在公开 Windows URI 契约。

## Deep link 决策

本分支不会注册、解析或接管猜测出来的 QQ 音乐 URI。由于没有验证当前 Windows 22.52 的实体 URI 语法，
照搬历史 `qqmusic://` 示例会增加未审计输入面，也可能抢占无关协议。因此界面不会显示虚假的接管开关，
也不存在需要恢复的注册表状态。

未来若官方客户端确实注册 scheme，必须记录准确的注册表所有者和命令，用脱敏的歌曲/专辑/歌单/歌手
样例在官方客户端中验证，并在重启后复查。完成这些证据后，YAQMC 才能增加白名单解析器和可回滚的用户
主动接管。
