# 播放权益

> **简体中文** | [English](../entitlement.md)

YAQMC 把目录元数据、账号权益、音源实际可用性和播放授权视为四个独立输入。QQ 适配器只向界面暴露
提供器无关的 `AudioQuality`、`AudioQualityPreference` 和 `PlaybackSourceSelection`，组件不能从会员
营销文字或音质标签推断权益。

认证校验通过同一白名单、可取消 transport 读取 `VipLogin.VipLoginInter/vip_login_base`，只消费数字
会员标记和到期时间。该兼容端点不可用或结构变化时，登录仍可使用，但权益变为 unknown，播放保守限制
到标准音质；取消不能被误当成这种回退。访客也按免费/标准处理，直到音源响应证明可用。

## 选择顺序

| 偏好   | 候选顺序                                       |
| ------ | ---------------------------------------------- |
| 自动   | 账号有权且可用的最高完整音源 → 标准 → 官方试听 |
| 标准   | 标准 → 官方试听                                |
| 高品质 | 高品质 → 标准 → 官方试听                       |
| 无损   | 无损 → 高品质 → 标准 → 官方试听                |
| 臻品   | 臻品 → 无损 → 高品质 → 标准 → 官方试听         |

免费账号自动选到标准是正常结果，不算回退。明确选择时：`account-rights` 表示歌曲有该音质但账号无权；
`source-unavailable` 表示账号有权但当前没有对应格式/vkey；`preview-only` 表示只有官方试听可播。缺权益
和缺音源在原生层保持不同错误。

臻品和加密无损通过账号绑定的 `GetEVkey/CgiGetEVkey` 请求。只有规范化权益与实时音源结果都允许时，
界面才显示实际选中音质。PlayerBar 选择只作用于当前歌曲，下一首恢复设置默认值。

## 授权生命周期

Cookie 和权益绑定 `(auth generation, opaque account scope)`，守卫随解析音源进入现有缓存、Range 和音频
引擎。注销/换号先取消旧 token、同步替换共享 epoch，再拒绝旧准备/加载/播放/提交，停止已加载旧音源，
最后发布脱敏 stopped 状态，不把它伪装成网络错误。访客公开音源使用不受账号生命周期限制的守卫。
