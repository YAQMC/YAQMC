Yet Another Q Music Client

把音乐、歌词与桌面
放回同一个节奏。

YAQMC 是面向 Windows 与 Linux 的非官方 QQ 音乐桌面客户端。原生音频、逐字歌词、账号音乐库与 桌面集成由一套权威播放状态驱动。

下载测试版 查看源代码

与腾讯或 QQ 音乐无从属关系；不绕过会员、地区、版权或账号权益。

一套状态，多个界面

桌面音乐客户端应该彼此一致。

01

原生播放，不用浏览器时钟猜进度

Rust PlayerService 统一队列、seek、随机/循环、试听时间轴、音质与错误；系统媒体面板和歌词共用真实音频时钟。

02

逐字歌词与悬浮表面

主歌词、桌面歌词、Lyrics Island 支持翻译与罗马音；锁定后仍保留独立悬浮解锁入口。

03

受限的 QQ / 微信 OAuth

登录发生在腾讯托管页面。凭据进入操作系统安全存储，歌词窗口与 OAuth 窗口没有账号命令权限。

04

音质由实际权益决定

标准、高品质、无损与臻品按账号权益和实时音源选择；授权 mflac 只在本地内存流式解密，磁盘保留密文。

05

Windows 与 Linux

提供多架构安装包、托盘、SMTC/MPRIS、输出设备与 Linux 诊断工具。Wayland 能力会如实标注限制。
