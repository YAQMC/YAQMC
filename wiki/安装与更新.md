# 安装与更新

从 [GitHub Releases](https://github.com/YAQMC/YAQMC/releases) 下载与你的系统和架构一致的文件。

## Windows

- 一般 Intel/AMD 电脑：`windows-x86_64`；
- 32 位旧电脑：`windows-i686`；
- Windows ARM：`windows-aarch64`；
- 安装使用 `.exe` 或 `.msi`，免安装使用 `portable.zip`。

## Linux

- Intel/AMD 64 位：`linux-x86_64`；
- ARM64：`linux-aarch64`；
- Debian/Ubuntu 可用 `.deb`，Fedora/openSUSE 可用 `.rpm`；其他发行版优先 AppImage。

```bash
chmod +x YAQMC*.AppImage
./YAQMC*.AppImage
```

每次都先核对 release 中的 SHA-256。测试版不会自动把“旧配置异常”归因于账号；完全退出旧进程后再启动
新版即可，除非明确诊断需要，不要手动清除操作系统安全存储。
