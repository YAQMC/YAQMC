# 开发者入口

需要精确 Node.js 26.7.0、Rust 1.88+，且原生构建必须能读取私有的
`qm-api-rs` 精确 pin。认证方式、分层构建与 QA profile 约束以仓库文档为准。

```powershell
npm ci
npm run dev:desktop
```

提交前运行：

```powershell
npm run docs:check
npm run format:check
npm run check
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --all-targets --locked
```
